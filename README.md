#	I chose the final project for IT 145: found in app development, the application was designed for a fictional client, Grazioso Salvare, to make an application for the tracking and intake of animals, dogs and monkeys, for use in rescue situations of people in difficult situations. I have used this artifact to demonstrate my abilities by creating three enhancements for the application. For the first enhancement, I created a user interface for the application instead of having the application run in the console or terminal. This enhancement was chosen to demonstrate my ability to design, develop, and deliver professional quality oral, written, and visual communications that are coherent, technically sound, and appropriately adapted to specific audiences and contexts and use well founded and innovative techniques, skills, and tools in computing practices for the purpose of implementing computer solutions that deliver and accomplish industry specific goals. The second enhancement I implemented a hash table to hold and sort objects stored in the application. I chose a hash table for this enhancement as the previous storage solution in the application was an array list, when an animal is searched for with the reserve animal command, the application would need to go down the list searching one at a time to find the right animal. With a hash table key the search would not need to search down the list, as long as there are not any animals stacked in the hash table the best case search could take less time at O(n) time for the search. This enhancement demonstrates my ability to design and evaluate computing solutions that solve a given problem using algorithmic principles and computer science practices and standards appropriate to its solution while managing the trade-offs involved in design choices. For the third I implemented an SQL database and a login function for the application. Creating a login system for the application would mitigate the risk of an unauthorized user from manipulating data in the application. Along with the login, passwords would be encrypted and stored in an SQL database and pulled for comparison when the user tries to login. This enhancement would demonstrate my ability in developing a security mindset that anticipates adversarial exploits in software architecture and designs to expose potential vulnerabilities, mitigate design flaws, and ensure privacy and enhanced security of data and resources.
